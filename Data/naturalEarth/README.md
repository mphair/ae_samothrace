# Natural Earth data — Samothrace area

GeoJSON extracts from [Natural Earth](https://www.naturalearthdata.com)'s
10m-scale vector layers, clipped to a box roughly 1000 miles (N-S) by
1000 miles (E-W) centered on Samothrace, Greece, and stripped down to
only the attributes this project uses. Generated by
`scripts/fetch_natural_earth.py` + `scripts/clip_natural_earth.py` — run
the first to download and unzip the raw, full-world Shapefiles into
`.desk_temp/natural-earth-raw/` (not committed; ~90 MB), then the second
to produce the files in this directory (~1.3 MB total) from that raw
data. Re-running either script is safe: both skip work that's already
done (an existing download, an existing output directory).

## Bounding box

Computed in `scripts/natural_earth_common.py`: 500 miles north, south,
east, and west of Samothrace's centroid (40.4833°N, 25.5333°E), each
offset computed independently via the standard
miles-per-degree-of-latitude/longitude approximation (not a true
geodesic square — see that file's own docstring for why that's an
acceptable simplification at this radius). As of this writing that
resolves to approximately:

| | |
|---|---|
| Center | 40.4833°N, 25.5333°E |
| Latitude range | 33.25°N to 47.72°N |
| Longitude range | 16.02°E to 35.05°E |

Covering roughly: all of Greece, the Aegean and Ionian seas, Cyprus,
western/central Turkey, the Balkans, Romania, Moldova, southern Ukraine
and Crimea, and parts of Hungary, Italy (the "heel" and "boot"), and the
Black Sea.

## Files

| File | Natural Earth layer | What it has |
|---|---|---|
| `ne_10m_coastline.geojson` | `ne_10m_coastline` | Coastline, as lines. |
| `ne_10m_land.geojson` | `ne_10m_land` | Mainland + larger islands, as polygons. Confirmed Samothrace's own outline is in here (see "A real gap" below for what's *not* in here: its name). |
| `ne_10m_minor_islands.geojson` | `ne_10m_minor_islands` | Smaller islets `ne_10m_land` generalizes away (58 in this box), as polygons. |
| `ne_10m_rivers_lake_centerlines.geojson` | `ne_10m_rivers_lake_centerlines` | Rivers, as lines, mostly named (e.g. Danube, Evros, Strymonas, Büyük Menderes). |
| `ne_10m_populated_places.geojson` | `ne_10m_populated_places` | Cities, filtered to population ≥ 50,000 or a national/regional capital (219 in this box — Istanbul, Athens, Ankara, Thessaloniki, ... down to small regional capitals). |
| `ne_10m_geography_regions_polys.geojson` | `ne_10m_geography_regions_polys` | Named islands/island groups only (filtered from a much larger regions layer): Crete, Rhodes, Lesbos, Cyprus, Cyclades, Ionian Is., and Pelopónnisos (tagged "Island" by Natural Earth despite being a peninsula — kept as their own data, not corrected here). |

Each feature's `properties` only carries the fields actually kept by
`clip_natural_earth.py` — every layer has ~25-170 attributes upstream
(multi-language name columns, per-country viewpoint columns, etc.);
see that script for the exact per-layer keep-list.

## A real gap: Natural Earth doesn't name Samothrace, or most Aegean islands

Two layers that look purpose-built for "island names" were tried and
dropped after inspecting the actual data:

- `ne_10m_minor_islands_label_points` has no `name` attribute at all in
  this release (only `featurecla`/`min_zoom`/`scalerank`) — despite
  being a "label points" layer.
- `ne_10m_geography_regions_points` (the point version of the layer
  used above) is a real named-point layer, but it's curated for
  notable/remote islands worldwide (Pacific atolls, sub-Antarctic
  islands, etc.) — it has **zero** features anywhere in this bounding
  box.

`ne_10m_geography_regions_polys` (what's actually used above) only
carries the short list of especially well-known islands/groups shown in
the table — not Samothrace, Lemnos, Thasos, Samos, Imbros/Gökçeada, or
most other individual Aegean islands. `ne_10m_populated_places` was
also checked directly for a "Samothraki" entry (the town sharing the
island's name) — it isn't there; too small a population for this
dataset. **If named small-island labels are needed later, they'll have
to come from a different, non-Natural-Earth source** (e.g.
OpenStreetMap), with its own separate citation and license — don't
expect a future re-run of this same pipeline with a different filter to
find them; they're not in the source data at all.
